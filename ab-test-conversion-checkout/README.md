# A/B-тест для страницы check-out в сервисе пожертвований: удаление предзаполненной суммы
Этот репозиторий демонстрирует мой подход к подготовке A/B-теста и интерпретации его результатов.
Изначально задача пришла в тестовом задании от потенциального работодателя. 
Кратко задача состояла в том, чтобы на основе принтскринов тестовой и контрольной групп отобрать метрики для оценки успешности изменения и далее провести оценку A/B теста.

Кратко сформулируем цель так: оценить, как удаление предзаполненной суммы на странице чекаута влияет на конверсию и выручку.

## TL;DR — результат
- Конверсия (CR) из окна чекаута в пожертвование выросла: тест 12.7% против 11.7% в контроле; двусторонний z-тест дал p-value = 0.003 → разница статистически значима.
- ARPU не снизился статистически значимо. Проверка проводилась непараметрическим (перестановочный тест) тестом .

## Рекомендация: выкатывать изменение и мониторить CR/ARPU после релиза.

## Сводка
- Период эксперимента: 2022-07-20 → 2022-07-26 (7 дней).
- Baseline CR: ~11.7%, MDE: +1 п.п., α=0.05, мощность 0.8.
- При таких вводных необходимый объём трафика: ~33 628 пользователей при 50/50.
